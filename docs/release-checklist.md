# Release checklist — plan §11

Each acceptance item with its evidence. **Verified** means an automated test or recorded manual run demonstrates it, and the cited test is named so it can be re-run. **Partial** says what is missing. Nothing is marked done on the basis of code reading alone.

Evidence basis: local runs on 2026-10-29 against commit `chore/release-evidence` (see the PR for exact counts and CI run), plus the real Base Sepolia run in [manual-testnet-smoke.md](manual-testnet-smoke.md). E2E uses a mock chain and fake wallet unless stated.
